Gil Odin Control 3 v0.7.0 Studio - 테스트 결과

통과:
- 순수 Java 정책 테스트: 독 표시 / 앱 분류
- 입력 라우터 및 최근 앱 정책 테스트
- Java 소스 15개 구문 파싱
- Android XML 리소스 전체 파싱
- Android 비공개 API 재사용 검사
- 통합 구조 검사: OdinTools 소스, 한국어 리소스, Dock Studio, 실제 앱 아이콘 미리보기, OEM 키코드 캡처, 서비스 실시간 갱신 연결

미실행:
- Android Gradle APK 컴파일
- 오딘3 실기기 UI / 터치 / OEM PServer / 물리 버튼 검증

사유:
- 현재 빌드 컨테이너에 Android SDK android.jar가 없음
- Gradle 8.9 배포본이 로컬에 없고 외부 네트워크가 차단되어 wrapper 다운로드 실패
- Windows 빌드 스크립트는 사용자의 기존 %LOCALAPPDATA%\GilAndroidBuildCache SDK 35 및 Gradle 8.9 캐시를 재사용하도록 구성

주의:
정적 검사 통과는 실제 APK 빌드나 오딘3 동작 성공을 의미하지 않음.
