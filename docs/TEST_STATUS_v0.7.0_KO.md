# v0.7.0 Studio 검증 상태

## 정적 검사로 확인된 항목
- 순수 Java 정책 테스트
- Java 소스 구문 파싱
- Android XML 리소스 파싱
- Android 비공개 API 재사용 검사
- 통합 구조 및 리소스 검사

## 아직 확인되지 않은 항목
- Android Gradle APK 컴파일
- 오딘3 실기기 UI/터치 동작
- OEM PServer 호출 및 펌웨어별 호환성
- 물리 버튼 입력/재매핑
- RetroArch 조합키의 실제 DOWN/UP 동작
- 장시간 실행 및 메모리 안정성

## 배포 판단
이 소스 스냅샷은 공개 협업을 위한 개발 버전입니다. 정식 APK Release가 아닙니다. CI 빌드가 성공하더라도 오딘3 실기기 검증은 별도로 필요합니다.
